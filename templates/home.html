How It Works

Client-Side Encryption

All encryption and decryption logic executes in JavaScript in your browser before messages are transmitted. The server only relays ciphertext.

Step-by-Step Traces

Inspect the intermediate math for any cipher: alphabet character shifts, modular arithmetic steps, and matrix multiplications are calculated and displayed in real time.

Decryption & Cracking

Test automated cryptanalysis including letter frequency scoring and key length detection, or walk through interactive manual decryption exercises.
