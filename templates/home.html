Architecture & Security Guarantees

Memory-only transport • Client sandbox
01
Client Ingress Sandbox

Plaintext enters directly through the local browser thread. Input buffers are processed in JavaScript and are never transmitted over HTTP or WebSocket in unencrypted form.

02
Cryptographic Execution Kernel

All mathematical transformations (modular additions, matrix products in GL(2, Z_26), and WebCrypto AES block expansions) run in client memory with intermediate arithmetic traces.

03
Opaque Relay Dispatch

The central server acts strictly as an in-memory transport broker. Opaque ciphertext packets are broadcast to room participants; no logs, records, or disk tables are maintained.
