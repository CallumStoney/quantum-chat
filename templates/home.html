QuantumChat

Disposable in-browser chat with client-side ciphers.

A small web experiment exploring how classical and modern ciphers actually work. Messages are scrambled locally right inside your browser before sending, and you can inspect or crack every payload in the lab.

Available Ciphers

Caesar Shift

The classic Roman alphabet shift (1 to 25 positions). Easy to set up and trivial to break with frequency analysis.

Experiment in Lab →

Affine Cipher

Linear modular substitution using a multiplier and an offset. The multiplier has to be coprime with 26 so the decryption inverse exists.

Experiment in Lab →

Hill Matrix

Multiplies blocks of letters against an invertible matrix mod 26. Breaks if the determinant shares a common factor with 26.

Experiment in Lab →

Vigenère

Shifts letters using a repeating keyword. Resisted simple frequency analysis for centuries until Kasiski trigram examination was discovered.

Experiment in Lab →

AES-256

The modern symmetric standard. Runs 14 rounds of byte substitution, row shifts, and column mixing directly in your browser.

Experiment in Lab →

BB84 Quantum (Simulation)

Simulates photon polarization basis matching between sender and receiver. Eavesdropping alters photon states and triggers detectable error rates.

Experiment in Lab →

How it works

In-memory only: Rooms exist purely in server RAM. When everyone disconnects, the room code and messages vanish completely.
Client-side encryption: When a cipher is selected, the plaintext is scrambled before leaving your browser. The server only relays ciphertext.
Live inspection: Click any message inside a room to see the raw ciphertext, character mapping, and modular math used.
