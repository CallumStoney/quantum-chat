Plaintext mode passes text through unchanged without encryption.

Caesar Cipher

Shifts every letter forward in the alphabet by a fixed number of positions (1 through 25).

How it works

Encryption is C = (P + shift) mod 26. Decryption just shifts backwards: P = (C - shift + 26) mod 26.

How to break it

Because there are only 25 possible shifts, you can brute-force all of them in a split second. In English text, the most frequent ciphertext letter usually maps back to 'E'.

Affine Cipher

Combines multiplication and addition: (a * x + b) mod 26, where a is a multiplier and b is an offset.

The coprime rule

The multiplier a must not share any common factors with 26 (gcd must be 1). If it shares factors with 2 or 13, different letters will collide onto the exact same ciphertext character and cannot be decrypted.

Decryption

To decrypt, find the modular inverse of a: P = a⁻¹ * (C - b) mod 26. For example, if a = 5, then a⁻¹ = 21 because (5 * 21) mod 26 = 1.

Hill Matrix Cipher

Encrypts blocks of letters as vectors by multiplying them against a key matrix mod 26: C = (K * P) mod 26.

Matrix invertibility

Decryption needs the inverse matrix mod 26. That only exists if the matrix determinant is non-zero and coprime with 26. If gcd(det, 26) != 1, you cannot invert the matrix to read the message.

Weaknesses

Because it is pure linear algebra, knowing just a few plaintext-ciphertext word pairs lets an attacker set up a system of linear equations and recover the key matrix immediately.

AES-256

The modern industry standard block cipher. Runs 14 rounds of substitution, row shifting, and column mixing over 128-bit blocks of data using a 256-bit key.

How each round works

Each round scrambles the data in four steps: SubBytes (non-linear S-box swap), ShiftRows (cyclic byte shifts), MixColumns (linear mixing matrix), and AddRoundKey (XOR with the round key).

This creates what cryptographers call the avalanche effect: changing a single bit in the original message completely flips roughly half of the output bits.

Vigenère Cipher

Shifts each letter using letters from a repeating keyword: C[i] = (P[i] + K[i mod len]) mod 26.

How it gets cracked

When common words in the message coincide with repetitions of the keyword, they produce repeated sequences in the ciphertext. Measuring the spacing between these repeats reveals the keyword length. Once the length is known, you can break it into separate Caesar shifts and solve each one with frequency analysis.

BB84 Quantum Key Simulation

A simulation of the classic 1984 quantum key exchange protocol using polarized photons.

Basis matching & eavesdropping

Alice sends photons in random bases (+ or ×), and Bob measures them with random bases. Afterwards, they announce which bases they used and keep only the bits where their bases matched.

If an eavesdropper tries to intercept the photons mid-flight, measuring them collapses quantum states, introducing roughly a 25% error rate in the matched bits and immediately giving the eavesdropper away.
